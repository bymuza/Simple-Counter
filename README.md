# Simple Counter Project 🔢

Ini adalah proyek coding pertama saya yang dibuat selama belajar di **Scrimba**. Aplikasi ini adalah sebuah penghitung (counter) sederhana berbasis web.

## 🚀 Fitur
* Menambah hitungan (+1)
* Mengurangi hitungan (-1)
* Desain responsif dan simpel

## 🛠️ Teknologi yang Digunakan
* **HTML5** - Untuk struktur halaman
* **CSS3** - Untuk styling dan tata letak
* **JavaScript** - Untuk logika fungsionalitas counter
* **Vite** - Sebagai build tool frontend

## 💻 Cara Menjalankan Proyek Secara Lokal
1. Clone repositori ini atau download folder proyek.
2. Buka terminal/command prompt di dalam folder proyek tersebut.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Jalankan server lokal:
   ```bash
   npm start
   ```
5. Buka tautan `http://localhost:5173` (atau port yang muncul di terminal) di browser Anda.
